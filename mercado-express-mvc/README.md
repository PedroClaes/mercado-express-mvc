## 🗄️ Banco de dados

Tabela **`TDS_MVC_TB_MERCADO`** (mesmo banco Oracle da Parte I), criada automaticamente pelo Hibernate (`ddl-auto=update`). Colunas: **Id, Nome, Tipo, Setor, Tamanho, Preco**.

```sql
CREATE TABLE TDS_MVC_TB_MERCADO (
    ID       NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    NOME     VARCHAR2(100) NOT NULL,
    TIPO     VARCHAR2(50),
    SETOR    VARCHAR2(50),
    TAMANHO  VARCHAR2(50),
    PRECO    NUMBER(10,2)
);
```

## ▶️ Como executar

1. Defina a senha do Oracle no `application.properties` (ou variável `DB_PASSWORD`).
2. Rode `MercadoExpressMvcApplication` (ou `./mvnw spring-boot:run`).
3. Acesse **`http://localhost:8080`** → redireciona para a listagem.
4. Clique em **Entrar** e use `admin / admin123` para liberar as ações de CRUD.

---

## 🧭 Como funciona o CRUD (por telas)

- **Listar (Read):** a home (`/produtos`) mostra a tabela de produtos. Pública.
- **Criar (Create):** botão **+ Novo produto** → formulário → **Salvar**.
- **Editar (Update):** botão **Editar** na linha → formulário preenchido → **Salvar**.
- **Excluir (Delete):** botão **Excluir** na linha (pede confirmação).

O mesmo formulário serve para criar e editar: um campo `id` oculto decide se o `save` do JPA faz **INSERT** ou **UPDATE**.
